# Быстрые ответы — плагин Agents Hub

Плагин страницы хаба (`hub-plugin.json`, API 1.1). Ядро и код хаба не меняет.

- Вариант в карточке вопроса сессии — кнопка: нажатие сразу отправляет ответ. Вопросов в карточке несколько — ответ
  уходит с выбором в последнем.
- Там, где выбирают несколько вариантов, остаются флажки и одна кнопка «Ответить».
- Свой ответ — поле с кнопкой отправки справа; Enter отправляет, Shift+Enter — новая строка.
- Выделенный в ленте текст не сбрасывается, когда лента обновляется, и копируется как обычно. Нажатие, которым закончили
  выделять, не сворачивает строку шага и не отвечает на вопрос.

## Поставить

```
hub market add <аккаунт>
hub market install <аккаунт>/hub-quick-answers
```

Плагин ставится закреплённым на коммите; новое — `hub market update quick-answers`.

## Выключить

«Настройки» → «Плагины» → выключить «quick-answers»: страница сама вернётся к прежним карточкам. Убрать совсем —
`hub market remove quick-answers`.

## Тесты

```
HUB_CORE=<папка хаба> python3 tests/test_quick_answers.py
```

Настоящая страница хаба на временном журнале в headless Chrome, мышь — событиями ввода. `QUICK_OFF=1` — та же страница
без плагина. Посмотреть глазами — `python3 tests/demo.py`.
